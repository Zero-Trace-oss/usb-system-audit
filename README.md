# USB System Audit Tool

## ⚠️ OGOHLANTIRISH (DISCLAIMER)
Ushbu vosita faqat **ta'lim maqsadida** va **o'z tizimingizni (yoki ruxsat berilgan laboratoriya muhitini)** audit qilish uchun yaratilgan. Ushbu dasturdan boshqa shaxslarning kompyuterlarida, ularning ruxsatisiz foydalanish qat'iyan man etiladi va qonun bilan taqiqlanadi. Muallif yuzaga kelishi mumkin bo'lgan har qanday noqonuniy harakatlar uchun javobgar emas.

## Nima qiladi?
Ushbu vosita USB fleshka orqali ishga tushirilib, Windows tizimining asosiy auditini o'tkazadi:
- Tizim haqida ma'lumot yig'adi (Protsessor, RAM, IP, Windows versiyasi).
- Saqlangan Wi-Fi profillarini ro'yxatlaydi (parollarsiz).
- Tizimda o'rnatilgan dasturlar ro'yxatini oladi.
- Natijalarni fleshka ichidagi `_Audit` papkasiga saqlaydi.

## Qanday ishlatiladi?
1. `start.bat` faylini ishga tushiring.
2. 15 soniya kuting.
3. Fleshka ichidagi `_Audit` papkasini ochib, natijalarni ko'ring.
